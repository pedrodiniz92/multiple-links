# Watch it!

A web application for organizing, viewing, and sharing YouTube videos with custom context and timestamps.

## Features

- Create curated lists of YouTube videos with custom titles and context
- Add and display timestamps for specific sections of videos
- Share your curated video lists with others via shareable links
- View videos in a split-screen interface while keeping your list visible
- Add text headers and formatted notes between videos
- Customize video titles through an easy editing interface
- Dark mode support with automatic detection of system preferences

## How It Works

1. **Add YouTube Links**: Paste YouTube URLs in the rich text editor, optionally with custom titles and context information
2. **Add Text & Headers**: Insert regular text or headers (using #) for organization
3. **View Videos**: Click on any video link to watch it in the right panel
4. **Share Lists**: Generate a shareable URL that preserves your entire curated list
5. **Customize Appearance**: Toggle between light and dark mode with the theme switch

## Special Syntax

- **Custom Titles**: `[t:Custom Title]https://youtube.com/watch?v=...`
- **Context Notes**: `[c:Additional context]https://youtube.com/watch?v=...`
- **Both Title and Context**: `[t:Custom Title][c:Context]https://youtube.com/watch?v=...`
- **Headers**: Start a line with `#` to create a section header
- **Line Breaks in Context**: Use `//` within context to create line breaks
